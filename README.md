# KidTube

YouTube-клиент для ребёнка. Родитель ведёт список разрешённых каналов в файле
`channels.json` в этом репозитории — приложение перечитывает его при каждом
запуске. Ребёнок видит только видео этих каналов: и в ленте, и в поиске, и в
рекомендациях.

Форк [SecFathy/KidTube](https://github.com/SecFathy/KidTube), Flutter, данные
через `youtube_explode_dart` (без API-ключей). Всё хранится локально в SQLite,
никакие данные ребёнка никуда не отправляются.

---

## Как добавить или убрать канал

Откройте [`channels.json`](channels.json) прямо на GitHub, нажмите карандаш,
поправьте список, сохраните. На телефоне — закрыть и открыть приложение
заново, либо потянуть главную вниз.

```json
{
  "version": 1,
  "channels": [
    "https://www.youtube.com/@SuperSimpleSongs",
    "@Smeshariki",
    "UCiGm_E4ZwYSHV3bcW1pnSeQ"
  ]
}
```

Годится любая из трёх форм записи: полная ссылка, `@handle` или сырой
`UC…`-идентификатор канала.

Что важно знать:

- **Файл — единственный источник правды.** Убрали канал из файла — при
  следующем запуске он и все его видео пропадут с телефона.
- **Пустой список ничего не удаляет.** Если файл недоступен, не читается или
  список в нём пуст, приложение оставляет всё как есть. Отключённый интернет не
  может стереть ребёнку каналы.
- Файл публичный — не кладите в него ничего личного.
- Правка `channels.json` не запускает пересборку APK.

## Как поставить APK

Открыть на телефоне эту ссылку — вход в GitHub не нужен, всегда отдаёт
свежую сборку:

**https://github.com/kstnkr-rgb/yousam/releases/latest/download/kidtube.apk**

Android спросит разрешение на установку из неизвестного источника.

> **Перед обновлением старую версию нужно удалить.** Сборка подписывается
> отладочным ключом, а его GitHub Actions создаёт заново на каждом запуске —
> подпись каждый раз другая, и Android откажется ставить новый APK поверх
> старого. Данные приложения при удалении пропадут, но это не страшно:
> каналы приедут из `channels.json`, видео перекачаются. Чтобы обновления
> вставали поверх, нужен постоянный keystore в секретах репозитория — см.
> ниже.

Собирается всё в GitHub Actions, локально ставить нечего. Сборка запускается
на каждый пуш в код; вручную — вкладка **Actions** → **Build APK** →
**Run workflow**. Там же в артефакте `kidtube-apk` лежит тот же файл, если
удобнее качать с компьютера.

Адрес `channels.json` подставляется в сборку автоматически из имени
репозитория. Если нужен другой файл, задайте его вручную:

```bash
flutter build apk --release --dart-define=CHANNELS_URL=https://raw.githubusercontent.com/USER/REPO/main/channels.json
```

Либо поменяйте адрес прямо в приложении: родительский режим → блок статуса →
**Адрес файла**.

### Чтобы обновления вставали поверх

Нужен один постоянный ключ подписи вместо отладочного, который CI создаёт
заново каждый раз. На машине с установленной Java:

```bash
keytool -genkey -v -keystore kidtube.jks -keyalg RSA -keysize 2048 -validity 10000 -alias kidtube
```

Файл `kidtube.jks` **в репозиторий не класть** — он публичный, и любой смог бы
подписать этим ключом чужой APK, который телефон принял бы за обновление.
Вместо этого: `base64 -w0 kidtube.jks` и в **Settings → Secrets and variables
→ Actions** завести `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_PASSWORD`,
`KEY_ALIAS`. Дальше в `android/app/build.gradle` добавляется `signingConfig`,
читающий их из окружения, а в workflow — шаг, восстанавливающий файл из
секрета. Сам `kidtube.jks` сохраните где-нибудь отдельно: потеряете — снова
придётся удалять приложение перед обновлением.

## Родительский режим

Долгое нажатие на аватар в правом верхнем углу → PIN (по умолчанию **1234**,
смените его в настройках).

В панели видно, когда список каналов загружался в последний раз и не было ли
ошибки. Оттуда же можно:

- принудительно перечитать `channels.json`;
- догрузить свежие ролики со всех каналов;
- добавить видео по прямой ссылке — такие видео живут отдельно от списка
  каналов и синхронизацией не удаляются;
- добавить канал **временно** — он исчезнет при следующем запуске, это только
  для быстрой проверки перед внесением в файл;
- заблокировать канал или удалить отдельные видео.

## Как это работает

- При добавлении канала выкачиваются последние **200** роликов и складываются в
  локальную базу — поэтому лента наполняется сразу, а поиск работает мгновенно
  и без интернета.
- Обновление (свайп вниз или кнопка в панели) досинхронизирует только новое:
  обход останавливается на первом уже известном видео.
- Поиск у ребёнка идёт **только по локальной базе**. Из этого экрана нет
  никакого пути к общему поиску YouTube.
- Рекомендации под плеером берутся из тех же разрешённых каналов: сначала
  другие ролики того же канала, потом остальные.

Настройки глубины синхронизации — в [`lib/utils/config.dart`](lib/utils/config.dart).
